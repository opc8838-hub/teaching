00 / 今天的目标

今天只求三件事

概念只讲到「够用」，剩下的时间全部用来动手。听懂了不算，做出来才算。

黎生 碳基社区 今天只讲一件事：把 AI 从聊天框里拉出来，真的把活干完。
01 / 说得清

分清五个词

用 30 秒、不用术语，向同事解释聊天机器人、工作台、智能体、工作流、技能分别是什么。

02 / 做得出

做出一个技能

把一件你反复做的事，写成一份带步骤、带标准、带「什么时候该问人」的说明书。

03 / 交得动

装成一个智能体

把技能装进一个岗位，给目标、给工具、给边界，然后交给它一个新任务。

今天不讲模型怎么训练、提示词玄学、写代码、怎么部署。这些等你先把活干完再说。

00 / 先测一下

这 5 句话，你信几句

都是我在群里、饭桌上、培训现场听到的原话。每句都只差一点——先别急着改，第 13 页我们一起改。

01豆包就是个聊天机器人。
02用了工作台，AI 就变得更聪明了。
03智能体会自己干活，交给它就不用管了。
04把提示词存下来，就是 Skill。
05工作流和智能体，基本是一回事。

先别改答案五句话各自差一个词。差的这个词，正好就是两个概念的分界线。

01 / 先分清

你晕，是因为两种词混着说

一个是「谁家的产品」，一个是「它凭什么干活」。产品会改名、会合并、会出新品；能力就那么几样。

产品名品牌层
谁家的东西
豆包 元宝 WorkBuddy 千问办公 豆包工作台 Coze / 扣子
能力名能力层
它凭什么干活
聊天 Chatbot 工作台 Workbench 智能体 Agent 技能 Skill 工作流 Workflow 连接器 Connector

同一个产品里可能同时有好几种能力。所以「豆包是不是智能体」这个问题，本身就问错了。

大致对应 · 版本会变，看能力不看名字
豆包
聊天智能体技能连接器
WorkBuddy
工作台智能体技能连接器
千问办公
工作台智能体技能

一句话先认能力，再认产品。下次别人跟你说一个新名字，先问：它属于哪一层？

01 / 一张图认全

六个问题，六个答案

这五个词不是同义词，因为它们回答的不是同一个问题。混着说，才会越听越乱。

Q1这是谁家的产品？
豆包 / WorkBuddy / 千问办公名字会换，别把它当能力
品牌层
Q2它怎么跟你说话？
聊天机器人你问一句，它答一句
交互方式
Q3它在哪儿干活？
工作台有任务、文件、产物、技能的地方
环境
Q4谁在干活？
智能体 Agent给目标，自己拆步骤、用工具、交成果
执行者
Q5它按什么方法干？
技能 Skill做法、标准、什么时候该问人
方法
Q6它按什么顺序干？
工作流 Workflow步骤提前定死，A → B → C
流程

记住这句下次听到一个新词，先问一句：它回答的是哪个问题？能对上号，就不会再晕。

01 / 一个比喻

把 AI 当成新来的同事

新同事能力再强，你只给他一个门口的位置，他也只能陪你聊天。

所以你缺的往往不是更聪明的 AI，是给他的「岗位」和「说明书」。

01 / 定义卡

五张卡，背下来就能用

每张卡三件事：一句话定义、一条判断特征、一个生活里的类比。

01 / Chatbot

聊天机器人

只会动嘴的顾问

你问一句，它答一句。给的是说法，不是东西。

像打电话咨询
02 / Workbench

工作台

给 AI 的一间办公室

任务、文件、产物、技能都在这儿。它没更聪明，只是能落地。

像给他一个工位
03 / Agent

智能体

能独立办完一件事的人

给目标，它拆步骤、用工具、自己检查，交一个成果。

像把活交办出去
04 / Skill

技能

一份岗位说明书

把做法、标准、什么时候该问人，存成能反复调用的文件。

像一张菜谱
05 / Workflow

工作流

一条流水线

步骤提前定死，A→B→C。稳定、可定时，但不会变通。

像一份 SOP

注意五张卡不是五个等级，是五样东西。一个人可以只有工位没有手册，也可以有手册但没有员工。

02 / 拆开看

智能体 = 目标 + 工具 + 循环 + 交付

判断一个东西是不是智能体，只看一件事：它有没有交给你一个能验收的东西。

01 / 目标

「把这件事办了」，不是「告诉我怎么做」。

02 / 工具

能读文件、能生图、能查资料、能发消息。

03 / 循环

做完会看，不对会改，不是一次就交。

04 / 交付

一个文件、一张表、一条已经发出去的消息。

反例只给文字方案的，还是聊天；给了文件但没自检的，是半成品；做完不问你对不对的，是没验收。

02 / 拆开看

技能 = 把「这一次」变成「每一次」

技能不是更长的提示词。它是一份带验收标准的说明书，换个人、换个主题，还能照做。

对比一段提示词一个技能
存在哪散在聊天记录里技能库，有名字
换个主题要重写一遍只换输入
谁能用只有你自己你、同事、下一个任务
会不会忘会，翻记录很痛苦不会，一直在那儿
怎么调用靠你复述点名就能用

一份合格技能，五个部件

01
适用场景管什么、不管什么，一句话写死
02
输入项每次要你提供哪几样东西
03
工作步骤先做什么、后做什么，不跳步
04
输出标准什么算做完、什么算不合格
05
停下来问人缺信息、涉密、要对外，必须停

最容易被忽略是第 5 条。没有「什么时候该问人」的技能，会自己编日期、编地点、编人名。

02 / 拆开看

智能体和工作流，只差一个问题

下一步，谁决定？

智能体 临场决定

  • 拿到目标后自己拆步骤，走哪条路看当时情况
  • 适合会变的活：写材料、做图、查资料
  • 代价：每次结果可能不一样，必须验收

工作流 事先定死

  • 步骤提前排好，每一步的输入输出都定死
  • 适合每次一样的活：周报、通知图、归档
  • 代价：情况一变就卡住，改流程比干活累

真实工作里工作流管骨架，智能体管骨头缝里的判断，人管签字。三者叠着用，不是三选一。

03 / 串起来

同一张封面，五种做法

看两列就够：你怎么说，和最后拿到什么。

你得多动手它替你动手
做法 你怎么说 它给你什么 你还要做什么
聊天机器人 「封面怎么写比较好？」 一段建议、三个标题方向 自己打开设计工具做图
工作台 把素材拖进去，一步步点 文件能存、能下载、能找到 每一步都要你亲手操作
智能体 「做一张 16:9 封面，标题是……，交付 PNG」 一个打开就能用的图片文件 验收文字和画幅
技能 「用我的封面技能，主题换成亲子阅读」 同样标准的一张图，不用再解释 只换输入，两分钟
工作流 设置一次，每月 1 号自动跑 到点就有图和记录 只做最后审核

关键它们不是互相替代，是一层层叠加。你会几层，就能把多少活交出去。

03 / 辨析

最容易混的四对

每对只有一个关键问题。记住问题，比记住答案有用。

Q1 · 谁决定下一步？
智能体临场判断，看情况走
VS
工作流事先定死，按顺序走

口诀：会看情况的，是智能体；按顺序走的，是工作流。

Q2 · 换个人、换个主题还能用吗？
技能能，换个输入就行
VS
提示词不能，得重写一遍

口诀：有名字、能被点名的是技能；粘完就忘的是提示词。

Q3 · 那是场地，还是人？
工作台场地：工位、文件、产物
VS
智能体人：有目标、会动手

口诀：场地不会替你干活，员工才会。

Q4 · 你给的是问句，还是目标？
聊天「怎么做？」要的是说法
VS
智能体「做出来。」要的是东西

口诀：问句要答案，目标要结果。

现场练把今天想交给 AI 的那件事，用一句话说成「目标」，而不是「问题」。说不出来，说明还没想清楚。

03 / 对答案

每句都差一点

不用判对错，把差的那一点补上，这句话就成立了。

01 豆包就是个聊天机器人。 → 豆包不只是聊天机器人。
02 用了工作台，AI 就变得更聪明了。 → 用了工作台，AI 变得更能干了。
03 智能体会自己干活，交给它就不用管了。 → 智能体会自己干活，交给它也要管。
04 把提示词存下来，就是 Skill。 → 把提示词整理成技能存下来，才是 Skill。
05 工作流和智能体，基本是一回事。 → 工作流和智能体经常一起用，但不是一回事。

所以不是「你错了」，是「话没说全」。把词说准，两个概念自然就分开了。

04 / 怎么学

别从工作流开始，会卡住

大多数人的失败，是一上来就搭流程，结果流程比活还复杂。顺序反过来就顺了。

01 STEP 01 先用一次智能体 先感受「交付物」是什么，别急着优化
02 STEP 02 把有效做法存成技能 这一次成了，才值得存；没成，存的是错误
03 STEP 03 把技能装进智能体 给它岗位、工具、边界，让它独立负责一类事
04 STEP 04 稳定之后再上工作流 重复到值得自动化的部分，才交给流水线

一句话先有「一次成功」，再有「一直成功」。今天只走到第 3 步，第 4 步留作课后作业。

第一件事：让它交个东西出来

别问它「封面怎么做」，直接让它做。你要的是文件，不是建议。

01
新建一个任务不要在刚才聊天的窗口里继续，新任务更干净
02
确认当前是 Agent 模式问答模式只会给你文字，干活模式才动工具
03

04

首轮指令 · 直接复制
请帮我做一张可以直接使用的活动封面图。

用途：单位内部通知的首页，也会投影展示
画幅：横版 16:9（1920×1080）
主标题：把阅读带回日常
副标题：单位读书分享会
风格：干净的瑞士网格排版，暖白底，
深蓝字，一点亮黄做强调，四周留文字安全区

要求：
1. 直接生成图片文件，不要只给文字描述
2. 生成后告诉我文件在哪里打开或下载
3. 中文标题请逐字核对，输出后提醒我人工检查
4. 如果当前模式不能生图，直接告诉我缺什么能力、
   该怎么切换

成功标准一个能打开的 PNG 或 JPG · 标题没有错字 · 画幅是 16:9 · 只有文字没有文件 = 没交付。

05 / 动手 · 18 分钟

把这次的做法，存成说明书

不是把提示词存一遍，而是写清「以后每次都怎么做」。左边填四项，右边自动生成。

五部件，提示词里都写进去了 ✓适用场景 ✓输入项 ✓工作步骤 ✓输出标准 ✓什么时候停下来问人

创建完，回到技能列表看一眼：它叫这个名字吗？点开能看到用途吗？

最常见的失败把「做好看一点」写进技能。它每次都会做得不一样，而且不会问你。

创建智能体的指令 · 复制后改名字


请基于我已保存的「活动封面助手」技能，创建一个智能体。

名字：活动封面管家
角色：单位里的活动视觉负责人，做过很多次内部活动的通知图，知道什么图能直接用。
目标：凡是活动封面，都做到「拿到就能发」，不用返工。
工具：读取我上传的文件、生成图片、保存到产物区。
可调用技能：活动封面助手

每次开始前必须先做：
1. 确认主题、主标题、使用场景、画幅
2. 缺信息就问我，一次最多 3 个
3. 先给 3 行方案，等我确认再动手

交付必须包含：
1. 图片文件 + 建议文件名
2. 按技能做了哪几步
3. 2 个我必须人工核对的地方

遇到这些情况必须停下来问我：
缺 2 项以上信息 / 涉及未公开材料或真实人名 / 要对外发布或花钱

请先复述你对这个岗位的理解，再等我给任务。

        

      

    


    
最容易漏是最后一段。不写「什么时候停下来问」，它就会自己补日期、补地点、补人名，而且补得很像真的。

  






  

    

      05 / 动手 · 8 分钟
      
新任务里，验四件事

      
换个主题，开一个新任务，把新任务交给这个智能体。然后只验这四条。

    


    

      

        

          01
          
它有没有先问清缺的信息？

          
通过先列缺项，或先给方案等你确认

          
没通过直接开干、自己补日期地点 → 回去补边界条款

        

        

          02
          
它有没有按技能的步骤走？

          
通过先方案、再出图、再自检

          
没通过跳步、直接给结果 → 点名技能，让它先复述步骤

        

        

          03

      06 / 现场
      
卡住了，先判断卡在哪一层

      
同一个「不行」，可能是四个不同层的问题。层找对了，动作只要一个。

    


    

      

        

          能力层
          
只给文字，没有图片

          
当前模式或模型不能生图，它只能把封面描述给你听。

          
→ 换一个带生图能力的模式，或明确要求「生成图片文件」

        

        

          能力层
          
图里的中文是错的

          
生图模型的中文本来就弱，越长的标题越容易糊。

          
→ 先让它出无字底图，标题用排版工具叠上去

        

        

          环境层
          
技能列表里找不到

          
创建对话里还差一步「保存 / 安装」，你停在预览页了。

          
→ 回到那个对话做完保存，再刷新技能列表

        

        

          方法层
          
新任务没按技能做

          
没点名调用，或者技能里只写了「做好看一点」。

          
→ 点名技能，让它先列出将遵守的步骤，再执行

        

      

    


    
安全三条不传未公开材料 · 不填真实人名 · 对外发布必须人审　｜　先分层能力不够不是你的错，边界没写清才要改。
