# 第一步 · 骨架（先只做“能跑能跳”）

复制到 DeepSeek 桌面版，只改【画风】【主题】【主角】。

```text
请做一个单文件 HTML 横版闯关游戏，先只做“能跑能跳”。

【画风】像素街机：16 位色、方块、亮绿和土黄；系统黑体。
【主题】恐龙丛林
【主角】小恐龙（孩子昵称：朵朵）
【骨架】左右跑、空格跳、重力、石台、镜头跟随；先不要敌人、蛋、Boss。
【操作】键盘 ← → 跑、空格跳；手机左下角左右键、右下角跳键。
【技术】单个 HTML 文件，无外部图片/字体/网络；打开即玩；60fps。
【验收】能左右跑；能跳上 100px 高的台子；掉进坑里能重来；手机按钮能用。
```

验收：轻点、按住都能跳上 100px 台子；掉坑能回检查点；没有敌人也能跑完全程。
