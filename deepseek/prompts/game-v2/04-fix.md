# 卡住时的六句话

不要自己改代码。把现象说清楚，让它改；改完自己点一遍。

| 现象 | 直接复制 |
| --- | --- |
| 跳不上去 | 轻点、按住都跳不上去；把跳跃改成固定高度，能上 100px 台子；不要短跳。 |
| 穿过平台 | 角色会穿过石台；检查碰撞，落下来要踩在台子上，不能穿过去。 |
| 踩不死贼 | 踩头没反应；检查踩头判定：从上方落下才消灭，碰侧面才扣心。 |
| Boss 打不死 | Boss 踩 3 下没死；检查 3 格血和归零判定，死后要能回巢结算。 |
| IP 不像 / 太丑 | 保持玩法不变，只换视觉：红银配色、发光眼、胸口计时器；不要用官方图片或 logo。 |
| 手机不能玩 | 加左下角左右键、右下角跳键；按钮至少 44 像素，别挡角色。 |

一句话原则：说现象，不说“你不行”；说哪一关、哪个台子、哪个按钮。
