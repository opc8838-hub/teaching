# 把自己的图放进游戏（IP / 角色 / 背景）

游戏已经能玩，但角色是 CSS 方块。想更好看，不用让 AI 重画，**把本地图片放进 `assets/`，让它接进去**。

## 一、准备什么

```
给孩子的游戏/
  dinosaur.html
  assets/
    hero.png      ← 主角，512×512，透明背景
    enemy.png     ← 敌人，512×512，透明背景
    bg.jpg        ← 背景，1920×1080
```

- 主角、敌人：**透明 PNG**，人物脚底在画布底部，不要留太多空白。
- 背景：**JPG/PNG**，1920×1080，不要有文字/水印。
- 文件名用英文，不要空格：`hero.png`、`enemy.png`、`bg.jpg`。
- 自己画的、拍的、有授权的图；自己家玩可以，不要商用、不要公开发布。
- 不要用官方 logo、官方角色图去要求 AI“复制”；用“感觉”描述。

## 二、提示词（直接复制）

```text
在现有游戏上，用本地图片替换 CSS 角色，不要重写玩法。

【素材】assets/hero.png 主角；assets/enemy.png 敌人；assets/bg.jpg 背景。
【规则】不要重画角色；不要拉伸；主角脚底对齐地面；碰撞盒保持原来的大小；图片缺失时用 CSS 画占位；手机能玩。
【限制】不要联网；不要官方 logo；图片只放在本地。
【验收】图片正常显示；角色踩在平台上；踩头判定不变。
```

## 三、再补一句“更好看”

```text
保持玩法不变，只做视觉优化：
- 背景加一层轻微暗角，让角色更突出；
- 主角脚下加一个椭圆阴影；
- 敌人加 1px 深色描边；
- 像素图用 image-rendering: pixelated，插画图保持比例 object-fit: contain；
- 不要把角色拉变形，不要加官方 logo。
```

## 五、验收与交付

- 打开 HTML：图片正常显示，没有破图。
- 角色脚底踩在平台上，不悬空、不陷进去。
- 踩头判定、掉坑、Boss 血条和原来一样。
- 手机横屏能玩。
- **交付是一个文件夹**：HTML + `assets/` 一起压缩；只发 HTML 会丢图。
- 如果一定要单文件：让 AI 把图片转成 base64 内嵌，但文件会变大，先备份。

## 六、卡住时

| 现象 | 一句话 |
| --- | --- |
| 破图 / 不显示 | 检查文件名大小写、路径 `assets/hero.png`、图片是否真的在文件夹里。 |
| 角色被拉扁 | 保持比例：`object-fit: contain`；不要同时写死宽高。 |
| 脚底悬空 | 让角色图片底部对齐平台顶部；调 `bottom` 或 `translateY`。 |
| 踩头判定变了 | 碰撞盒保持原来大小，只换图片，不改 hitbox。 |
| 手机上太大 | 用 `max-width:100%`；角色宽度用相对单位。 |
