00 · 先做环境自检，再写提示词

大家用的都是 DeepSeek 桌面版，但网络环境不一样。先确认三件事：模型、联网、来源。

三件事　① 模型选最新可用；② 桌面版自带联网搜索，不需要额外插件；③ 国外网站打不开不影响日报，默认用国内来源。
自检 1 · 联网能不能用
请用联网搜索查一条今天的国内 AI 新闻，给我标题、链接、日期。
如果打不开或不能联网，直接说“无法联网”，不要编。
自检结果说明怎么办
给出标题 + 链接 + 日期联网可用正常做日报
说“无法联网”搜索被禁用 / 断网切“资料包模式”
给链接但打不开被墙 / 登录墙换国内来源，或资料包
自检 2 · 不能联网时的资料包模式
我不能联网。下面是今天的 3 条材料：
1. 【标题】……【链接】……【原文/摘要】……
2. 【标题】……【链接】……【原文/摘要】……
3. 【标题】……【链接】……【原文/摘要】……
请只基于这 3 条写今天的日报；不要补充外部事实；没有的信息写“材料未提及”。
国内优先来源　AI：机器之心、量子位、36Kr、InfoQ 中文、官方中文博客；教育：教育部/教育局/学校/中国教育报；金融：央行/统计局/交易所/巨潮/第一财经；本地：政府/政务公开/平台规则中心。GitHub、arXiv、OpenAI/Google 官方博客：能打开才用，不作为必须。

01 · 游戏：三步 + 换素材

先骨架，再玩法，再 Boss + 皮肤；最后才换本地图片。每一步做完，先自己点一遍。

第 1 步 · 骨架（只做“能跑能跳”）

游戏 · 骨架提示词
请做一个单文件 HTML 横版闯关游戏，先只做“能跑能跳”。

【画风】像素街机：16 位色、方块、亮绿和土黄；系统黑体。
【主题】恐龙丛林
【主角】小恐龙（孩子昵称：朵朵）
【骨架】左右跑、空格跳、重力、石台、镜头跟随；先不要敌人、蛋、Boss。
【操作】键盘 ← → 跑、空格跳；手机左下角左右键、右下角跳键。
【技术】单个 HTML 文件，无外部图片/字体/网络；打开即玩；60fps。
【验收】能左右跑；能跳上 100px 高的台子；掉进坑里能重来；手机按钮能用。

第 2 步 · 玩法（不重写骨架）

游戏 · 玩法提示词
在现在的游戏文件上，加玩法，不要重写骨架。

【偷蛋贼】地面巡逻；碰到侧面扣 1 颗心；踩头消灭，踩完弹一下。
【收集】3 颗蛋、金币；捡蛋加分，金币加分。
【检查点】每过一段放一个检查点；掉坑回检查点，扣 1 颗心。
【终点】走到巢边过关；3 颗心用完失败。
【验收】踩头能死；碰侧掉心；3 颗蛋都能捡；能走到终点。

第 3 步 · Boss + 皮肤

游戏 · Boss + 皮肤提示词
在现在的游戏文件上，加 Boss 和皮肤；不要重写前两关。

【偷蛋王】3 格血，在终点前巡逻；踩 3 下打死；碰到侧面扣心；死后回巢过关。
【Boss 血条】画在 Boss 头上；踩中时闪白、掉一格。
【皮肤】保持玩法、关卡、数值不变，只换视觉：主角换成「红银配色、发光眼睛、胸口计时器、光之巨人感觉」；敌人换成紫色小偷；背景换成夜晚城市。
【限制】不要使用任何官方图片 / logo；全部用 CSS/SVG 画。
【验收】Boss 能打死；正好 3 下；回巢结算；手机能玩。

第 4 步 · 把自己的图放进去（IP 素材）

先把图放进文件夹　assets/hero.png（主角，512×512 透明 PNG）、assets/enemy.png、assets/bg.jpg（1920×1080）。文件名英文、不要空格。交付变成“HTML + assets 文件夹”。
游戏 · 用自己的图提示词
在现有游戏上，用本地图片替换 CSS 角色，不要重写玩法。

【素材】assets/hero.png 主角；assets/enemy.png 敌人；assets/bg.jpg 背景。
【规则】不要重画角色；不要拉伸；主角脚底对齐地面；碰撞盒保持原来的大小；图片缺失时用 CSS 画占位；手机能玩。
【限制】不要联网；不要官方 logo；图片只放在本地。
【验收】图片正常显示；角色踩在平台上；踩头判定不变。

参考方向 A · 跑酷（一条提示词）

跑酷 · 一条提示词
做一个单文件 HTML 跑酷游戏。

【玩法】小恐龙自动往前跑；空格 / 点屏幕跳；躲石头、树桩、偷蛋贼；捡蛋和金币加分；60 秒；3 颗心；结束算分。
【画风】像素街机：16 位色、方块、亮绿和土黄。
【主题】恐龙丛林
【技术】单个 HTML 文件，无外部图片/字体/网络；手机能玩。
【验收】能跳、能加分、60 秒结束、手机能玩。

参考方向 B · 益智推箱子（一条提示词）

推箱子 · 一条提示词
做一个单文件 HTML 推箱子游戏。

【玩法】7×7 网格；小恐龙推蛋到草窝；只能推不能拉；3 关；方向键 / WASD；Z 撤销；R 重来；全部归位过关。
【画风】像素街机：深绿底、亮绿角色、米白蛋。
【主题】恐龙丛林
【技术】单个 HTML 文件，无外部图片/字体/网络；手机有方向键。
【验收】3 关都能过；撤销能用；手机能玩。

卡住时 · 一条一条复制

跳不上去
轻点、按住都跳不上去；把跳跃改成固定高度，能上 100px 台子；不要短跳。
穿过平台
角色会穿过石台；检查碰撞，落下来要踩在台子上，不能穿过去。
踩不死贼
踩头没反应；检查踩头判定：从上方落下才消灭，碰侧面才扣心。
Boss 打不死
Boss 踩 3 下没死；检查 3 格血和归零判定，死后要能回巢结算。
IP 不像 / 太丑
保持玩法不变，只换视觉：红银配色、发光眼、胸口计时器；不要用官方图片或 logo。
手机不能玩
加左下角左右键、右下角跳键；按钮至少 44 像素，别挡角色。

02 · 日报：先手跑，再每天

DC 必须开着；到点是把提醒投进原会话，AI 再去做。先手跑一期，再建每天 07:30。

第 1 步 · 手跑一期（只改三处）

日报 · 手跑提示词（国内来源版）
你是我每天 07:30 的简报助手。请生成今天的《AI 行业日报》。

【读者】我，35 岁，产品经理；早上只有 5 分钟；我要判断今天要不要调整产品方向。
【时间窗】过去 24 小时（北京时间）；只写这个窗口内的新信息。
【来源】优先国内可访问：机器之心、量子位、36Kr、InfoQ 中文、官方中文博客；GitHub / arXiv 能打开才用；至少 3 个来源，每个带标题、链接、日期。
【可访问性】只写能打开的页面；打不开就换国内来源；完全无法联网就写“今天无法联网”，不要编。
【固定栏目】
1. 今天最重要的 3 条：每条 1 句事实 + 1 句“对我意味着什么”（每条不超过 80 字）。
2. 今天可以试的 1 个小动作：30 分钟内能做完。
3. 来源列表：标题 + 链接 + 日期。
【规则】
- 先搜索再写；没有可靠来源就写“今天没有值得报的”，不要编。
- 不重复过去 7 天已经写过的内容；必须重复时标注“延续”。
- 中文，300–500 字；不堆形容词；不写“震撼”“炸裂”。
- 最后一句：今天要不要跟进（要 / 不要 / 观察）。
【输出】直接给日报，不要解释过程。

第 2 步 · 变成每天 07:30

日报 · 建每日任务（整段复制）
请在当前会话创建一个每日定时任务：

- 标题：AI 行业日报
- 时间：每天 07:30，Asia/Shanghai
- 提醒内容：下面这段完整日报指令，到期时按它执行：

你是我每天 07:30 的简报助手。请生成今天的《AI 行业日报》。

【可访问性】只写能打开的页面；打不开就换国内来源；完全无法联网就写“今天无法联网”，不要编。
【固定栏目】
1. 今天最重要的 3 条：每条 1 句事实 + 1 句“对我意味着什么”（每条不超过 80 字）。
2. 今天可以试的 1 个小动作：30 分钟内能做完。

【规则】
- 先搜索再写；没有可靠来源就写“今天没有值得报的”，不要编。
- 不重复过去 7 天已经写过的内容；必须重复时标注“延续”。
- 中文，300–500 字；不堆形容词；不写“震撼”“炸裂”。
- 最后一句：今天要不要跟进（要 / 不要 / 观察）。
【输出】直接给日报，不要解释过程。

请调用 schedule_create 创建，创建后把任务卡给我看。

第 3 步 · 先做 2 分钟测试

日报 · 2 分钟测试
请创建一个 2 分钟后触发的一次性任务，标题「日报测试」，
提醒内容：这是测试，请回复“测试已触发”。到点后告诉我。
创建后把任务卡给我看；测试完我会删除。
DC 必须开着　可以最小化，不能退出；电脑不能睡眠；网络要通。关掉/睡眠时不会投递；重开后重复任务只补最近一次错过的时点。任务绑定原会话，不要删/归档。

没收到 / 报告不对 · 一条一条复制

有回执，没报告
打开关联会话，手动说：补一份今天的日报，按原格式；不要等下一次。
来源打不开
这些链接打不开；请换国内可访问的来源，重新给 3 条，必须带标题、链接、日期；不要编。
内容太泛
每条加一句“对我意味着什么”；最后给“要 / 不要 / 观察”；不要写新闻摘要。
每天重复
不重复过去 7 天已经写过的内容；必须重复时标注“延续”。
时间不对
检查时区是不是 Asia/Shanghai；改完先建一个 2 分钟测试，确认回执。
任务不见了
重新建一个，标题和提醒内容照旧；不要删任务绑定的会话；建完做 2 分钟测试。
