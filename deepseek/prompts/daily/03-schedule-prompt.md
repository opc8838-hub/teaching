# 03 · 变成每天 07:30

**前提：DC 一直开着**（可以最小化，不能退出；电脑不能睡眠）。

## 做法

1. 打开 DC → 左侧「自动化任务」→「新建」。
2. 它会打开一个新会话；在这个会话里发下面这段。
3. AI 会调用 `schedule_create`，生成任务卡。
4. 点任务卡「打开」，确认：每天、07:30、Asia/Shanghai、下次运行时间。

```text
请在当前会话创建一个每日定时任务：

- 标题：AI 行业日报
- 时间：每天 07:30，Asia/Shanghai
- 提醒内容：下面这段完整日报指令，到期时按它执行：

你是我每天 07:30 的简报助手。请生成今天的《AI 行业日报》。
【读者】我，35 岁，产品经理；早上只有 5 分钟；我要判断今天要不要调整产品方向。
【时间窗】过去 24 小时（北京时间）；只写这个窗口内的新信息。
【来源】优先国内可访问：机器之心、量子位、36Kr、InfoQ 中文、官方中文博客；GitHub / arXiv 能打开才用；至少 3 个来源，每个带标题、链接、日期。
【可访问性】只写能打开的页面；打不开就换国内来源；完全无法联网就写“今天无法联网”，不要编。
【固定栏目】
1. 今天最重要的 3 条：每条 1 句事实 + 1 句“对我意味着什么”（每条不超过 80 字）。
2. 今天可以试的 1 个小动作：30 分钟内能做完。
3. 来源列表：标题 + 链接 + 日期。
【规则】
- 先搜索再写；没有可靠来源就写“今天没有值得报的”，不要编。
- 不重复过去 7 天已经写过的内容；必须重复时标注“延续”。
- 中文，300–500 字；不堆形容词；不写“震撼”“炸裂”。
- 最后一句：今天要不要跟进（要 / 不要 / 观察）。
【输出】直接给日报，不要解释过程。

请调用 schedule_create 创建，创建后把任务卡给我看。
```

## 先做 2 分钟测试

正式开每天之前，先建一个一次性任务：

```text
请创建一个 2 分钟后触发的一次性任务，标题「日报测试」，
提醒内容：这是测试，请回复“测试已触发”。到点后告诉我。
```

到点后：

- 自动化任务页能看到「任务运行记录」回执；
- 原会话能看到提醒/回复；
- 测试完删除。

## 改时间 / 删除

- 改时间：自动化任务 → 任务 → 规则 → 运行时间 → 每天 → 改时间/时区 → 保存修改。
- 删除：任务详情 → 更多任务操作 → 删除。
- 任务绑定原会话；不要删/归档那个会话。
