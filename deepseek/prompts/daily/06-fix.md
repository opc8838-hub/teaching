# 06 · 失败手册

| 现象 | 先查 | 一句话 |
| --- | --- | --- |
| 7:30 没动静 | DC 开着？电脑睡眠？网络？ | “DC 还开着吗？电脑睡眠了吗？任务列表里下次运行时间对吗？” |
| 有回执，没报告 | 原会话 | “打开关联会话，手动说：补一份今天的日报；不要等下一次。” |
| 内容很空 / 很泛 | 来源 | “加 1 个主来源；每条必须有标题、链接、日期。” |
| 每天重复 | 去重 | “不重复过去 7 天；建一份日报台账，写完追加一行。” |
| 时间不对 | 时区 | “检查是不是 Asia/Shanghai；改完先建 2 分钟测试。” |
| 国外网站打不开 | 来源 | “换国内可访问来源；GitHub/arXiv 不是必须；不要编链接。” |
| 任务不见了 | 删除/归档 | “重新建一个，标题和提醒内容照旧；不要删任务绑定的会话。” |
| 报告太长 | 栏目 | “只留 3 条 + 1 个动作；每条不超过 80 字。” |
| 像新闻摘要 | 缺“so what” | “每条加一句：对我意味着什么；最后给要/不要/观察。” |

## 隐私边界

- 不要把 API Key、密码、公司机密、孩子隐私贴进提示词。
- 只让 AI 读公开来源；不要在日报里复述内部会议内容。
- 自己家玩可以；公开发布要重新检查版权和隐私。
