# 08 · 框架与方法论

## 一句话

**先定“早上要做什么决定”，再定“日报长什么样”，最后才定“怎么定时”。**

## 三层模型

### 1. 读者层（先想清楚）

- 谁看：我 / 伴侣 / 团队。
- 几点看：6:50 / 7:30 / 8:30。
- 看完做什么决定：跟进 / 不跟进 / 观察。

### 2. 信息层（日报的内容）

- 范围：一个主题，不要四个。
- 时间窗：过去 24 小时；周报用 7 天。
- 来源：3 个主来源 + 1 个备选。
- 栏目：3 条事实 + 1 个动作 + 来源。
- 规则：无来源不写；不重复；失败兜底。

### 3. 运行层（每天跑起来）

- 频率：每天 / 周一至周五。
- 时区：Asia/Shanghai。
- 宿主：DC 必须运行；电脑不能睡眠。
- 验收：任务在、回执有、会话有报告、来源能打开。

## 不同背景，怎么带

不要按“职业”分，按**早上的决定**分：

| 早上要做的决定 | 日报栏目 | 来源 |
| --- | --- | --- |
| 今天产品要不要调整 | 3 条 AI + 1 个可试 | 机器之心 / 量子位 / 36Kr（GitHub/arXiv 可选） |
| 今天仓位要不要动 | 3 条宏观 + 1 个风险 | 央行 / 统计局 / 公告 |
| 今天怎么陪孩子 | 3 条政策/方法 + 1 个亲子动作 | 教育部 / 学校 / 儿科 |
| 今天店里做什么 | 3 条本地/平台 + 1 个跟进 | 政府 / 平台公告 |

## 成熟度阶梯

- **L1 手跑**：会写提示词，能生成一期。
- **L2 定时**：每天 07:30 自动投递，DC 保持运行。
- **L3 质量**：来源稳定、去重、有结论、能验收。
- **L4 扩展**：周报 / 第二主题 / 邮件或飞书推送（稳定 7 天后再做）。

## 混合背景课堂怎么带

1. 先让每个人填画布，不写提示词。
2. 只改三处：读者、来源、栏目。
3. 手跑一期，互读：5 分钟能不能做决定。
4. 建每天任务，做 2 分钟测试。
5. 只讲一个失败手册，不追求全覆盖。
6. 课后作业：连续 7 天，每天标一条“错/旧/不相关”。

## 评估标准

- 有一个每天任务，下次运行时间正确。
- 有一个 2 分钟测试回执。
- 报告至少 3 个来源，日期是新的。
- 读者能在 5 分钟内做一个决定。
- 知道 DC 关掉/睡眠会错过。
