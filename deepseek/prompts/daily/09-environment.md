# 09 · 电脑环境与搜索工具

## 先说结论

- 所有学员用同一个 DeepSeek 桌面版，但**网络环境不一样**：有人能开 GitHub，有人打不开；有人公司网络限制搜索。
- 日报**不要求**国外网站；默认用国内可访问来源。
- 桌面版自带**联网搜索 / 网页读取**；不需要额外装搜索插件。
- 如果搜索被禁用或完全不能联网：改用“资料包模式”，不要硬等。

## 开课前 3 分钟自检

在会话里发这一句：

```text
请用联网搜索查一条今天的国内 AI 新闻，给我标题、链接、日期。
如果打不开或不能联网，直接说“无法联网”，不要编。
```

三种结果：

| 结果 | 说明 | 怎么办 |
| --- | --- | --- |
| 给出标题 + 链接 + 日期 | 联网可用 | 正常做日报 |
| 说“无法联网” | 搜索被禁用/断网 | 用资料包模式 |
| 给链接但打不开 | 来源被墙/登录墙 | 换国内来源，或资料包 |

## 国内优先来源

### AI / 科技

- 机器之心、量子位、36Kr、InfoQ 中文、新智元、CSDN、掘金。
- 官方中文博客/公众号（DeepSeek、智谱、月之暗面、阿里云、腾讯云、百度飞桨等）。
- GitHub Trending、arXiv、OpenAI/Google 官方博客：**能打开才用，不作为必须**。

### 教育 / 亲子

- 教育部、省/市教育局、学校官网/公众号、中国教育报、央视新闻。
- 儿科/心理机构官网；不要用未署名自媒体当唯一来源。

### 投资 / 商业

- 央行、国家统计局、证监会、上交所/深交所、巨潮资讯、第一财经、财新。
- 公司公告优先于媒体解读。

### 本地 / 小生意

- 本地政府/政务公开、平台规则中心（淘宝/抖音/美团/微信公众平台）、行业协会。

## 资料包模式（不能联网时）

老师提前准备 3 条今天的材料（标题 + 链接 + 一段原文/截图），让学员粘贴：

```text
我不能联网。下面是今天的 3 条材料：
1. 【标题】……【链接】……【原文/摘要】……
2. ……
3. ……
请只基于这 3 条写今天的日报；不要补充外部事实；没有的信息写“材料未提及”。
```

这样仍然能练“结构、取舍、so what”，只是不练“实时搜索”。

## 搜索工具怎么讲

- 用桌面版自带的**联网搜索**；不是让家长再装一个浏览器插件。
- 让 AI **先搜索、再写**；要求“标题 + 链接 + 日期”。
- 打不开的链接，要求它**换来源**，不要编。
- 日报里至少 3 个来源；每个来源都能点开。
- 如果 AI 说“无法联网”，不要反复重试；直接切资料包。

## 模型与账号

- 设置 → 模型 → 选**最新可用**；日报用 flash 够，游戏大改可用 pro。
- 任务绑定创建它的会话；不要删/归档；换模型后先做一次 2 分钟测试。
- 每个人用自己的桌面版/账号；不要共用同一个会话。

## 环境矩阵

| 环境 | 游戏 | 日报 | 方案 |
| --- | --- | --- | --- |
| 国内普通网络 | 可以 | 可以（国内源） | 默认 |
| 国外站点打不开 | 可以 | 可以 | 去掉 GitHub/arXiv |
| 公司网络限制搜索 | 可以 | 受限 | 手机热点 / 资料包 |
| 完全断网 | 可以 | 不可以 | 资料包模式，只练结构 |
| 笔记本会睡眠 | 可以 | 会错过 | 改电源设置，或换常开机 |
