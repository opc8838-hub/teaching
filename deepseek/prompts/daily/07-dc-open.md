# 07 · DC 保持运行

## 结论

**DC 必须运行，任务才会到点投递。**

- 可以最小化；不能退出。
- 电脑不能睡眠；睡眠时宿主不运行。
- 网络要通；断网时投递/生成可能失败。
- 关掉后重开：任务还在；重复任务只补**最近一次**错过的时点，不补全部。
- 任务绑定原会话；可以冷恢复；不要删/归档那个会话。

## Windows 设置

1. 设置 → 系统 → 电源 → 屏幕和睡眠。
2. “接通电源时，使设备进入睡眠状态”设为 **从不**。
3. 笔记本合盖：电源按钮/合盖 → **不采取任何操作**（插电时）。
4. 不要用“关机/重启”代替“最小化”；更新重启后，任务还在，但会错过重启期间的时点。

## 适合放日报的机器

- 家里常开的台式机/笔记本；插电。
- 不要放在会自动休眠的笔记本上。
- 如果只有一台电脑，早上先打开 DC，再去做别的事；不要 7:29 才开机。

## 任务运行记录

- 自动化任务 → 任务 → 任务运行记录：看投递时间。
- 关联会话：看报告有没有生成。
- 记录只证明投递；不证明模型执行完成。
