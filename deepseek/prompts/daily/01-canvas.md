# 01 · 日报画布

先填这张，不要先写提示词。

```text
读者：谁看？____________________
场景：几点看？通勤 / 早餐 / 开工前？____________________
决定：看完要做什么决定？____________________

范围：AI / 教育 / 金融 / 本地 / 其他：____________________
时间窗：过去 24 小时 / 过去 7 天：____________________

来源 1：____________________
来源 2：____________________
来源 3：____________________
备选来源：____________________

栏目 1：____________________
栏目 2：____________________
栏目 3：____________________
最后一句：要 / 不要 / 观察

形式：300–500 字；几条；要不要链接：____________________
规则：无来源不写 / 不重复过去 7 天 / 失败兜底：____________________
交付：先只在会话里看；稳定 7 天再谈推送
```

## 填不出来，先回答三个问题

1. 你早上最想知道的**一件事**是什么？
2. 如果今天只能看**三条**，你想看哪三类？
3. 看完这条，你**今天会做什么动作**？

## 示例

- 读者：我，35 岁，产品经理，早上 7:30 通勤。
- 范围：AI 模型 / 工具 / 论文，过去 24 小时。
- 来源：官方博客、GitHub Trending、arXiv。
- 栏目：3 条动态 + 1 个可试动作 + 来源。
- 规则：无来源不写；过去 7 天不重复。
- 交付：会话里看，先不推送。
