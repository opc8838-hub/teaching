GAME LAB / 先玩再选

三个方向，
先玩一遍。

同一个课程，三种“手在干什么”：横版闯关、跑酷、益智推箱子。孩子喜欢哪个，就做哪个；不要三个都做。

回到主课件 → 讲师提示词手册 课程首页
01 / 横版闯关

恐龙蛋大冒险

左右跑、跳平台、踩贼头、捡 3 颗蛋，最后打偷蛋王。有探索，也有 Boss。

3 分钟一局 · 点开就玩 →
02 / 跑酷

恐龙快跑

自动往前跑，一键跳；躲石头、树桩和贼，捡蛋加分。60 秒，追高分。

60 秒一局 · 点开就玩 →
03 / 益智

恐龙推蛋

方向键推蛋进草窝，只能推不能拉；3 关，能撤销、能重来。越推越绕。

5 分钟一局 · 点开就玩 →
手机横屏　三个都可以在手机横屏玩；如果按钮挡住角色，点右上角/右下角空白处先收起提示。
课程用法　先让孩子选一个，再回主课件 P4 选方向、P6 填设计卡；不要三个都做。
