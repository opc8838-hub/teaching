# 从会聊天，到会干活

**AI Agent 入门第一课 · 碳基社区 · 黎生**

[打开在线课件](https://opc8838-hub.github.io/teaching/)

面向 35–45 岁零基础职场人的现场课。用「一间办公室」把五个总被混着说的词讲清楚，
再带学员从**做一张图**走到**存成一个技能**，最后**装成一个智能体**。

## 这门课讲什么

1. 聊天机器人、工作台、智能体、工作流、技能——五个词分别回答什么问题
2. 智能体 = 目标 + 工具 + 循环 + 交付；技能 = 把「这一次」变成「每一次」
3. 现场做一张封面图，再把做法存成技能，最后装成一个能交办任务的智能体
4. 验收：先问没问、按没按步骤、是不是真文件、有没有告诉你核对什么

## iPad 投屏

1. Safari 打开本页 → 分享 → **添加到主屏幕**
2. 从主屏幕图标进入：没有地址栏和工具栏，整屏就是课件
3. 横屏使用；**上下或左右轻扫**翻页，也可以点右下角箭头
4. 需要放大细节时，两指捏合缩放

> 直接镜像整个屏幕也能放，但会带上 Safari 的地址栏。加到主屏幕更干净。
