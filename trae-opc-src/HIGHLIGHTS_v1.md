# TRAE OPC Talk 课件重做 —— 每页亮点清单 v1

> 2026-11-19。重做原则：每页都要有一件"真东西"（真实对话、真实文件、真实数据、真实界面录屏），而不是一段总结。
> 题目不变：《一个想法，一个人，1689 个案例》。约 55 分钟分享 + 10 分钟互动。

## 一条主线

**一个想法 → 变成知识 → 写成 Skill → 一个人搭成产品 → 打磨体验 → 用真需求迭代 → 摔过的跤**

每章开头一句"这一章回答什么问题"，结尾一句"带走什么方法"，前后能接上。
